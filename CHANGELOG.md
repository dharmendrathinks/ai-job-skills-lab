## v0.1.0 — 2026-09-10

Initial private prerelease for engineering evaluation, containing the complete
seven-phase implementation sequence. Publication does not mark pending human
quality reviews or activation gates complete.

- **P1:** fork foundation, research/application routing, private state boundaries
  and protected public-template defaults (`d102a88`).
- **P2:** reviewed collection/imports, qualified Codex subscription extraction,
  exact evidence spans, deterministic aggregates and withdrawal (`29cca75`).
- **P3:** inspected non-job context, four distinct draft workflows and reviewed
  evidence-profile proposals (`5d8fc8f`).
- **P4:** decisions/outcomes, repetition controls and reviewed interchange (`ff5babf`).
- **P5:** measured provider/language coverage, translation review and stable-window
  comparisons (`121bdcd`).
- **P6:** bounded incremental operation, durable review inbox, managed offline
  reports/recovery and optional reviewed scheduling/delivery (`09bc20d`).
- **P7:** explicit immutable backend/platform workspaces using the shared pipeline,
  descriptive cross-domain views and domain-aware interchange (`10e2ae3`).
- Updated README, contributor/security/conduct guidance, application setup routing,
  release procedure and GitHub templates for this project. Removed the inherited
  sponsorship configuration; upstream attribution remains visible.
- Preserved the upstream MIT notice, added copyright for AI Job Radar additions,
  and retained Apache-2.0 provenance for the identified runtime adaptation.

See [release notes](docs/releases/v0.1.0.md) for validation, compatibility and
remaining gates. No provider, schedule, notification, personal setup or repository
visibility change is activated by this release.
