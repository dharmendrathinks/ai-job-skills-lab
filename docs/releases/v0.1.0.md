# AI Job Radar v0.1.0

Initial **private prerelease for engineering evaluation**, dated 2026-09-10.
AI Job Radar extends Mads Lorentzen’s AI Job Search foundation into a global
AI engineering research workspace. The complete seven-phase implementation is
included; human quality acceptance and optional activation gates remain open.
The repository remains private.

## Included

1. Fork foundation and research/application separation with protected templates.
2. Reviewed evidence collection/imports, qualified subscription extraction,
   exact-span validation, conservative deduplication and retention/withdrawal.
3. Four evidence-linked drafts: learning, open-source work, product hypotheses
   and YouTube experiments, backed by inspected non-job context.
4. Reviewed decisions/outcomes, evidence-profile proposals and scoped interchange.
5. Coverage/language evidence, reviewed translations and comparable-window controls.
6. Bounded incremental runs, review inbox, managed offline HTML and recovery;
   explicit configuration/review paths for scheduling and notifications.
7. Opt-in backend/platform workspaces with immutable domain binding, shared
   workflows, descriptive comparisons and domain-aware interchange.

Phase 7 is commit `10e2ae3`. Earlier phase commits and detailed changes are in
[CHANGELOG.md](../../CHANGELOG.md). The release tag identifies the final source
including documentation. No compiled binaries, model weights or research datasets
are attached; the source includes clearly identified owned test fixtures.

## Start and compatibility

Read [README.md](../../README.md) and run the read-only research preflight.
Python 3.10+ macOS/Linux supports the research helpers. The model path currently
qualifies only the recorded Codex CLI 0.153.4 macOS arm64 binary/configuration and
gpt-5.5 with existing ChatGPT sign-in. See [runtime qualification](../research/runtime.md);
a newer or different installation is not automatically compatible. No API-key or
paid fallback is configured. Job-data services budget remains ₹0.

Existing P2–6 AI state keeps its original taxonomy. Use the supported current
writer and [managed recovery](../research/continuous-operations.md); do not restore
an older withdrawal/operations ledger or downgrade private state from Git.
Backend/platform requires an explicitly selected empty private data workspace
and immutable binding. No corpus copy or historical reclassification occurs.
AI interchange remains 1.0; backend uses 1.1 with an exact matching pack. The
separate AI Trend Radar consumer has not been upgraded for that extension.
Application workflows and upstream tests remain present; personal application
onboarding stays blocked in this development template.

## Open gates and known limitations

- Representative human extraction, translation and brief-quality review remains
  pending; the roadmap’s 120-description/40-employer targets are not achieved results.
- Only the narrow Jobicy path is reviewed for explicit collection. Its review
  expires 2026-10-09; it samples remote jobs with capped coverage. Other providers
  remain conditional. No complete global-market or growth result is claimed.
- Comparable historical windows and broader stable-cohort evidence remain absent.
- Scheduled account use and sleep/wake reliability need further evidence.
  Schedules and notifications are off; current Jobicy permissions forbid exports.
- Local inference has not been promoted; an exploratory run with errors does not
  establish quality or memory fit.
- Backend labels need human adjudication and wider evaluation; matching-input
  backend baselines and the separate Radar 1.1 consumer remain outstanding.
- Retention supports compatible logical deletion and derived-artifact invalidation,
  not hard physical-erasure deadlines, hosted recall or unmanaged backup control.
